# Kkulog (꾸로그)

월간 캘린더에서 일정과 메모를 관리하는 데스크톱 앱입니다.
React로 캘린더와 일정 편집 화면을 만들고, Tauri를 이용해 데스크톱 창에서 실행하도록 구성했습니다.
일정 데이터는 Express API를 통해 PostgreSQL에 저장합니다.

## 주요 기능

- **일정 관리** — 제목, 메모, 날짜, 색상을 입력해 일정을 추가하고 수정·삭제할 수 있습니다.
- **월간 캘린더** — 이전·다음 달로 이동하며 일정을 확인하고, 여러 날에 걸친 일정은 이어지는 막대로 표시합니다.
- **모달에서 일정 편집** — 일정 바를 더블 클릭하면 편집 창이 열리고, 날짜 선택기로 시작일과 종료일을 변경할 수 있습니다.
- **회원가입·로그인** — 아이디 중복 확인, 로그인·로그아웃, 쿠키를 통한 로그인 상태 확인을 구현했습니다.
- **창 크기에 따른 표시 조정** — 창 높이에 맞춰 일정 표시 줄 수를 조정하고, 작은 창에서는 일정을 얇은 막대로 표시합니다.

## 구현 이야기

### 월을 넘어가는 일정 조회

달력에는 이전 달과 다음 달의 날짜도 함께 보이기 때문에, 조회 기준을 해당 월이 아닌 **화면에 보이는 날짜 범위**로 잡았습니다. 서버에서 조회 범위와 일정 기간이 겹치는지 확인해, 범위 밖에서 시작해 안쪽에서 끝나는 일정도 가져오도록 했습니다.

### 여러 날에 걸친 일정 배치

기간 일정을 주 단위로 나누고 시작 위치와 길이를 계산해 막대로 표시했습니다. 같은 날짜에 일정이 겹치면 다른 줄에 배치합니다.

날짜 셀은 날짜 표시만 담당하고, 일정 바는 별도 레이어에서 그리도록 나눴습니다. 계산한 일정 바를 주별로 묶어 각 주에 필요한 항목만 렌더링합니다.

### 월 이동과 작은 창에서의 표시

한 번 조회한 일정은 최대 6개월분까지 메모리에 보관해 같은 월을 다시 볼 때 재사용합니다. 일정이 바뀌면 현재 월의 캐시도 함께 갱신합니다.

창 높이에 따라 표시할 일정 줄 수를 제한하고, 높이가 500px 이하일 때는 제목을 숨기고 색상 막대만 표시하도록 했습니다.

조회·저장 시간을 확인하기 위한 [테스트 데이터 생성 및 성능 측정 스크립트](backend/scripts)도 작성했습니다.
